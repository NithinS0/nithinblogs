# Nithin S - Portfolio

A modern, interactive portfolio website showcasing my work as an AI enthusiast, ML practitioner, and Python developer.

## 🌟 Features

- **Interactive 3D Elements**: Built with React Three Fiber and Drei
- **Responsive Design**: Works on all device sizes
- **Smooth Animations**: Powered by Framer Motion
- **Modern UI**: Styled with Tailwind CSS
- **Performance Optimized**: Built with Vite for fast loading times

## 🚀 Technologies Used

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS
- **3D Graphics**: Three.js, React Three Fiber, Drei
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel, Netlify

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/NithinS0/nithinblogs.git
   ```

2. Navigate to the project directory:

   ```bash
   cd nithinblogs
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

## ▶️ Running the Project

### Development Mode

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
